
# Predictive Motion Tracking IoT

![Build Status](https://github.com/dhrutimahadik5106/predictive-motion-tracking-iot/actions/workflows/main.yml/badge.svg)

## Project Description
A low-cost multi-sensor predictive motion tracking
and threat detection system using ESP32 and
ultrasonic sensors.

## Features
- Real-time motion tracking
- Multi-sensor data processing
- Predictive motion analysis
- Machine learning integration
- Web dashboard for monitoring
